# Riddler – Kreuzworträtsel

Kreuzworträtsel und Schwedenrätsel erzeugen, am Bildschirm lösen oder auf A4 drucken – komplett offline.

**App:** https://zl0thdev.github.io/riddler-app/ (im Browser „Zum Home-Bildschirm“ bzw. „App installieren“)

Dieses Repository enthält nur die fertig gebaute App (Stand c7a057a); der Quellcode liegt in einem privaten Repository.
